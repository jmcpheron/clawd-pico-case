# Inputs

Design files contributed by people working on this repo, kept byte-for-byte as
received. They are evidence of where a design came from, not build sources:
the parts are rebuilt in `cad/` from rows in `MEASUREMENTS.md`, and the
rebuild is checked against these files. Each file's origin, licence and
SHA-256 are logged in `PROVENANCE.md`.
